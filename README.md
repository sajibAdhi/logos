# Sajib Adhikary Brand Assets

## Variant naming

- Prefix the standard, unvaried version with `original-`, such as `original-favicon.ico`,
  `original-icon-32.png`, and `original-logo-horizontal.png`.
- Put the variant after the asset type and size: `favicon-dark.ico`, `icon-32-dark.png`,
  and `logo-dark.png` for dark artwork; use `-light` for light artwork.
- Use `original-` for an unvaried source asset, not `normal-`; keep descriptive auxiliary
  files such as previews and diagrams named for their content.

The website uses the dark artwork on light backgrounds and light artwork on dark
backgrounds.
