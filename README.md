# Sajib Adhikary Brand Assets

## Variant naming

- Put the variant at the end of the asset name. Standard assets use the `-original`
  suffix, such as `favicon-original.ico`, `icon-32-original.png`, and
  `logo-horizontal-original.png`.
- Put the variant after the asset type and size: `favicon-dark.ico`, `icon-32-dark.png`,
  and `logo-dark.png` for dark artwork; use `-light` for light artwork.
- Keep descriptive auxiliary files such as previews and diagrams named for their content.

The website uses the dark artwork on light backgrounds and light artwork on dark
backgrounds.
