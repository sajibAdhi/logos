# Sajib Adhikary Brand Assets

## Variant naming

- Assets without a theme prefix are the standard, unvaried version, such as `favicon.ico`,
  `icon-32.png`, and `logo-horizontal.png`.
- Use `dark-` for dark-colored artwork, such as `dark-favicon.ico`, `dark-icon-32.png`,
  and `dark-logo.png`.
- Use `light-` for light-colored artwork, such as `light-favicon.ico`, `light-icon-32.png`,
  and `light-logo.png`.

The website uses the dark artwork on light backgrounds and light artwork on dark
backgrounds.
