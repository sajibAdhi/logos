# Sajib Adhikary Brand Assets

## Variant naming

- Assets without a theme prefix are the standard, unvaried version, such as `favicon.ico`,
  `icon-32.png`, and `logo-horizontal.png`.
- Put the variant after the asset type and size: `favicon-dark.ico`, `icon-32-dark.png`,
  and `logo-dark.png` for dark artwork; use `-light` for light artwork.
- Keep unvaried assets unprefixed, such as `favicon.ico`, `icon-32.png`, and
  `logo-horizontal.png`.

The website uses the dark artwork on light backgrounds and light artwork on dark
backgrounds.
